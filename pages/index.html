This is a public information page—not TherapyBot itself.

Do not enter vault passphrases, private messages, trauma histories, medical records, or other sensitive information on this site. The working app must be installed and opened locally at 127.0.0.1. This website has no chat, login, forms, local model connection, or record storage.

What we're building

Useful support.
On your terms.

The software is designed to help you explore difficult questions without mandatory accounts or surveillance. It is an evolving prototype, not a clinical service.

01 / CONVERSATION

Talk things through

Connect a compatible GGUF model running on your own Windows or Linux computer. Local inference is optional for journaling and reference browsing.

02 / LOCAL RECORDS

Choose whether to save conversations. Keep journal entries in a passphrase-protected local vault, with local search and data-management controls.

03 / REFERENCE LIBRARY

Run privately

The application runs locally.

GitHub Pages cannot operate a private Python server or run a GGUF model. This public page is a starting point for installing the real application on your own machine.

1

Get the source

Follow the current Windows and Linux setup instructions. The project is free to run but still experimental.

2

Configure your local model

Install your own compatible GGUF runtime, such as KoboldCPP or llama.cpp. No commercial inference API or third-party account is required.

3

Open localhost, not this site

Launch the Python app and open its loopback URL in your browser. Protect your passphrase and review the documentation's storage and model-safety limits.

A tool for reflection, not a therapist.

TherapyBot is not clinically validated, does not diagnose or prescribe, and cannot provide emergency care. Its model and crisis detection can make serious mistakes. In the US, call or text 988 for crisis support; call emergency services for immediate danger.
